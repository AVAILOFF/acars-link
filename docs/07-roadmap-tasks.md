# 07 — Roadmap и карточки задач

Оценки — для одного разработчика. Карточку берёт пользователь: «делай T03».

## Этап 0 — Решения (до кода)
Ответы пользователя на вопросы из `08-risks-open-questions.md`. Фиксируются в `02`/`03`.

## Этап 1 — Ядро без симулятора (MVP-логика)

### T01 — Каркас монорепо
pnpm workspace, TypeScript strict, Biome, Vitest. Пакеты `core`, `scenarios`, `transport`. Скрипты typecheck/lint/test. Обновить команды в CLAUDE.md.
**Готово, когда:** пустые пакеты собираются, тест-заглушка зелёная, CI-скрипт локально проходит.

### T02 — Нормализация OFP SimBrief
Тип `Ofp`, парсер из JSON v2, единицы (kg/lbs → kg), unit-тесты на 2–3 обезличенных примерах.
**Готово, когда:** все поля из `06` маппятся, ошибки формата дают понятное исключение.

### T03 — Clock, Rng, TelemetrySnapshot
Интерфейсы, seeded Rng, тип снимка (см. `03`), генератор синтетического профиля полёта.

### T04 — FSM фаз полёта
По `04`: фазы, гистерезис, пауза и simRate, discontinuity, OOOI, сериализация.
**Готово, когда:** синтетические профили (норма, go-around, пауза, телепорт) дают ожидаемые последовательности фаз в снапшот-тестах.

### T05 — Форматтер и DisplayProfile
Перенос строк по ширине, uppercase, фильтр символов, разделители. Профиль по умолчанию + B77x/B78x из оригинала.

### T06 — Движок сценариев v0
YAML + JSON Schema, триггеры `phase_enter/time/distance/event`, `probability`, `cooldown`, шаги `send/wait`. Без `reply/branch`.

### T07 — 15 базовых сценариев
Из списка MVP в `02`. Тест: каждый прогоняется на 3 синтетических полётах.

## Этап 2 — Реальный мир

### T08 — Мост MSFS (C#)
SimConnect → WebSocket 127.0.0.1, реконнект, pause/simrate. **Проверка человеком** в MSFS.

### T09 — Транспорт Hoppie + Mock
Очередь, rate limit, backoff, ping/telex/poll. Mock для тестов. **Проверка человеком**: telex доходит в Fenix/FBW.

### T10 — Desktop-оболочка + UI
Ввод SimBrief username и Hoppie-кода (в keychain), старт/стоп, лента сообщений, текущая фаза, настройки сценариев.

### T11 — Запись и replay телеметрии
Запись JSONL из моста, прогон в ядре, CLI для отладки сценариев.
