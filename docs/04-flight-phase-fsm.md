# 04 — Машина фаз полёта

Главный источник событий для сценариев. Вход — поток `TelemetrySnapshot` (~1 Гц) и OFP. Выход — текущая фаза и события переходов.

## Фазы

```
PREFLIGHT → BOARDING → PUSHBACK → TAXI_OUT → TAKEOFF → CLIMB → CRUISE → DESCENT → APPROACH → LANDED → TAXI_IN → ON_BLOCK → (TURNAROUND | DONE)
                                                     ↑                                 │
                                                     └──────── GO_AROUND ──────────────┘
```

| Переход | Условие (черновик, подобрать на записях) | Устойчивость |
|---|---|---|
| PREFLIGHT → BOARDING | старт полёта пользователем, на земле, двигатели выкл. | сразу |
| BOARDING → PUSHBACK | маяк ON и (тормоз снят или GS > 1 kt назад) | 5 с |
| PUSHBACK → TAXI_OUT | любой двигатель работает и GS > 5 kt | 10 с |
| TAXI_OUT → TAKEOFF | на земле, GS > 40 kt | 3 с |
| TAKEOFF → CLIMB | `onGround=false` и AGL > 500 ft | 5 с |
| CLIMB → CRUISE | alt ≥ (крейсерский эшелон OFP − 1000 ft) и \|VS\| < 500 | 60 с |
| CRUISE → DESCENT | VS < −800 fpm и alt < крейсерский − 2000 ft | 60 с |
| DESCENT → APPROACH | AGL < 5000 ft или < 30 nm до пункта назначения | 10 с |
| APPROACH → LANDED | `onGround=true`, GS > 30 kt | 2 с |
| APPROACH → GO_AROUND | VS > +500 fpm и AGL рос после < 1000 ft | 5 с |
| LANDED → TAXI_IN | GS < 30 kt | 5 с |
| TAXI_IN → ON_BLOCK | GS < 1 kt, тормоз ON, все двигатели выкл. | 10 с |
| *+ TAKEOFF → TAXI_OUT* | *прерванный взлёт: на земле, GS < 20 kt* | *10 с* |
| *+ CLIMB → DESCENT* | *VS < −800 fpm (эшелон OFP не достигнут: короткий рейс, уход на запасной)* | *60 с* |
| *+ GO_AROUND → CLIMB* | *AGL > 5000 ft и VS > 0 (уход на запасной)* | *10 с* |
| *+ GO_AROUND → APPROACH* | *VS < +300 fpm (горизонт/снижение на повторный заход)* | *10 с* |
| *+ ON_BLOCK → TURNAROUND \| DONE* | *решение пользователя* | *сразу* |

Строки *курсивом с «+»* добавлены в T04: без них FSM застревает. Подобрать на записях вместе с остальными.

Реализация: `packages/core/src/phase/fsm.ts`. Таймеры устойчивости идут по «времени полёта» (Δt снимков × `simRate`, без пауз); OOOI OUT — тормоз снят и GS ≥ 1 kt 3 с подряд (время — начало движения); DISCONTINUITY — скачок позиции > 2 nm + 1,5 × GS × Δt полёта; ALT_CHANGE — новый уровень (±1000 ft, |VS| < 300) держится 30 с.

Step climb в крейсере — событие `ALT_CHANGE`, а не смена фазы.

## Требования

- **Гистерезис и устойчивость:** условие должно держаться N секунд (колонка «Устойчивость»).
- **Пауза и ускорение времени:** при `paused` таймеры устойчивости не идут. Внутреннее «время полёта» масштабируется с `simRate`.
- **Телепорт и слью:** скачок позиции > X nm за тик → событие `DISCONTINUITY`, FSM не делает ложных переходов.
- **Потеря телеметрии:** нет данных > 30 с → `TELEMETRY_LOST`. Сценарии ставятся на паузу, фаза сохраняется.
- **Возобновление:** состояние FSM сериализуется. После рестарта приложения полёт продолжается.
- **OOOI-события:** OUT (тормоз снят и движение), OFF (отрыв), ON (касание), IN (on block) — с временем UTC.

## Производные величины для триггеров

- `distToDestNm`, `distToTodNm` (TOD из навлога OFP, `ident == "TOD"` `[ПРОВЕРИТЬ]` формат навлога), `etaUtc`.
- `minutesToSchedOut` / `minutesSinceOff`.
- `fuelStable` (стабилизация после заправки, как в оригинале: допуск ~100 кг, 2+ замера).

## Тестирование

- `tools/replay`: запись телеметрии в JSONL + OFP → прогон через FSM → снапшот последовательности фаз.
- Нужны записи: нормальный полёт, уход на второй круг, повторный запуск двигателей на рулении, полёт с паузой и ×4, телепорт на ВПП (без руления), обрыв SimConnect.
- Синтетические генераторы профилей для юнит-тестов (без MSFS).
