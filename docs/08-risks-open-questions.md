# 08 — Риски и открытые вопросы

## Решения этапа 0 (зафиксированы 2026-10-07)

1. **Оболочка:** Electron.
2. **Мост:** C# / .NET 8; SimConnect — через свою DLL `acars_simconnect.dll` (C++, клиент SimConnect слинкован статически из официального MSFS SDK; T73, решение 2026-10-31; раньше — managed-обёртка SDK).
3. **Симуляторы:** MSFS 2020/2024. X-Plane 12 — позже (T18); ядро и протокол моста не завязываем на MSFS.
4. **Бэкенд и LLM:** на старте не нужен. Только бесплатные API без ключей. Бэкенд — опционально, T16.
5. **Транспорт:** Hoppie на старте, SayIntentions позже (T17).
6. **Название:** пока нет, кодовое `acars-sim`. **Позывной станции:** настраиваемый шаблон (`OPS{flight}`, `{airline}OPS`, свой). По умолчанию `OPS{flight}`, как в оригинале. Причина: по `tech.html` Hoppie один позывной может держать только один logon code (лок снимается через 100 с), а `{airline}OPS` чаще конфликтует у разных пользователей. Распространяется ли лок на поле `from` telex (и на станции XATC `X…` у разных пользователей) — `[ПРИ РЕЛИЗЕ]`.
7. **Язык UI:** английский + русский (i18n с первого дня). ACARS-сообщения — всегда английский, верхний регистр.
8. **Самолёты для проверки человеком:** Fenix A320, PMDG 777, iniBuilds A350, iniBuilds A380, iniBuilds A340. iFly 737 MAX 8 исключён (пользователь, 2026-10-23): в нём сейчас нет поддержки CPDLC.
9. **Распространение:** на старте — **личное использование**, чтобы оценить реалистичность. Установщик, подпись кода и автообновление (T19) пока не нужны. Если решим выпускать в сообщество — **до релиза** письмо владельцу Hoppie (hoppie@hoppie.nl): допустимость использования, схема позывного, лок на `from`, HTTPS/POST, длина telex. Затем лицензия репозитория, подпись (T19), проверка условий всех API для публичного использования, в том числе таблиц сквоков (EUROCONTROL CAL, ICAO APAC eANP — T24) и данных VATSpy (CC BY-SA 4.0, T23).

## Риски

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| Нарушение этикета или правил Hoppie (спам, поддельные станции) → блокировка | средняя | высокое | rate limit, изучить правила, связаться с владельцем сети до публичного релиза |
| Различия в отображении telex в аддонах | высокая | среднее | DisplayProfile + проверка человеком по чек-листу |
| Изменения SimConnect / MSFS 2024 | средняя | среднее | изоляция в мосту, версия протокола |
| FSM ошибается на нестандартных полётах | высокая на старте | высокое | replay-записи, discontinuity, ручной override фазы в UI |
| Однообразие контента | средняя | высокое | data-driven сценарии, вероятности, кулдауны, флаги между рейсами |
| Юридическое: копирование кода или ассетов RealAcars | низкая при соблюдении правил | высокое | инвариант 1, писать с нуля |
| Утечка ключей API | — | высокое | ключи только на бэкенде или в keychain пользователя |
| Лимиты бесплатных API (TheSpaceDevs, Overpass) | средняя | низкое | кэш, деградация |

## Известное неизвестное

- Точная грамматика ответов Hoppie poll и ограничения длины.
- Поведение SIMULATION RATE и паузы в MSFS 2024.
- Ширина строк для каждого аддона.
- Устроен ли сервер автора RealAcars (87.106.57.67) как Hoppie-станция. Нам не нужен, но интересен как референс фич (клиренс, step climb).

## Решения и сверка 2026-10-22

- **Лицензия:** проприетарная (All rights reserved + EULA); подпись кода не делаем (T19, `07`).
- **Проверка человеком на основных самолётах — пройдена** (сообщил пользователь, 2026-10-22): Fenix A320, PMDG 737, PMDG 777, iniBuilds A380, iniBuilds A350. iniBuilds A340 — пройдена (сообщил пользователь, 2026-10-23): на стоянке и полный полёт. iFly 737 MAX 8 из списка исключён — нет поддержки CPDLC. Отдельные открытые `[ПРОВЕРИТЬ]` в `07` по этим самолётам пользователь не перечислял и автоматически не закрыты.
- **Hoppie, сверка с tech.html и faq.html (2026-10-22).** Пользователь принёс сводку из внешнего источника; она **не является ответом владельца** и в части утверждений расходится с сайтом, поэтому пункт 1 «Отложено до релиза» не закрыт. По сайту: лок — связка logoncode + network + callsign, 100 с, после любого запроса кроме peek и ping, ошибка `callsign already in use`; про поле `from` **не сказано**. POST разрешён и рекомендован (URL лучше держать до 256 символов). Максимальной длины сообщения для Hoppie **нет**; «около 4 КБ» — это про реальный ACARS, сайт просит не слать килобайты. Правил по именам станций (`OPS…`, `X…`) нет: callsign не ограничивается, но вопрос допустимости не решён. Опрос — раз в 45–75 с случайно, до раза в 20 с короткое время после отправки, таймаут 15 с. Условий для сторонних клиентов и коммерции на сайте нет; на странице «All rights reserved, including text and data mining». Контакт: hoppie@hoppie.nl. Остаётся: письмо владельцу (лок на `from` и станции `X…` у разных пользователей, допустимость `OPS<рейс>`).
